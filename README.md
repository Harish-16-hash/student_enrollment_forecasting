# Student Enrollment Forecasting Using Deep Learning

## 📌 Project Overview

Student Enrollment Forecasting is a deep learning-based project that predicts future student enrollment using historical enrollment data. The system uses an Artificial Neural Network (ANN) to learn patterns from student and admission data and provide enrollment forecasts.

## 🎯 Objectives

- Predict future student enrollment using historical data.
- Analyze important factors affecting enrollment.
- Apply deep learning techniques for forecasting.
- Evaluate the prediction performance of the ANN model.
- Provide a simple web interface for enrollment prediction.

## 🧠 Algorithm Used

**Artificial Neural Network (ANN)**
